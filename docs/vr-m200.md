# M200 manual rotating bolt

Either hand can operate the actual right-side bolt handle. The left hand uses an
overhand grasp; the right hand selects between its two palm facings. With the
other hand supporting the gun, use Trigger to grasp the handle. Lift, pull, push,
then lower the handle. Releasing the trigger retains the mechanical position.
Regripping the rear grip requires a neutral trigger before firing again.

## Authority and lifecycle

The existing detachable-magazine owner now has an explicit manual-bolt feed
policy. It still owns the magazine, reserve, live chamber and ammunition
transactions. `manual_bolt.hpp` owns the retained bolt coordinates, spent case,
cocking state and the cartridge in transit; these are per weapon, not per hand.
It never runs from skinning, either eye or native prediction replay.

Lift and translation are sequential constraints. A locked bolt cannot move
rearward; a rearward bolt cannot rotate closed. A committed shot consumes only
the chambered round and leaves a spent case. Crossing 85% rearward travel ejects
that case, or discards one live cartridge if the chamber/feed rail was loaded.
95% rearward travel arms a new feed. Forward passage through 35% travel takes
one round from the magazine; reaching the front seats it, and lowering the handle
locks the action. Those contact tolerances are a first physical interaction
calibration and need headset acceptance.

Removing a magazine during a partial feed leaves the in-transit cartridge on
the gun. Reversing that stroke ejects it once. Magazine removal/reinsertion is
manual; partial extraction does not detach or refill a magazine. Cartridge
transfers retain the same native loaded total; firing/live ejection debit once.
Spent cases are not ammunition. Empty trigger presses can release the cocked
striker but cannot feed the action.

Base and desert receivers also accept a forward strike on the lower
`j_clip_release` paddle with any part of the held spare's body. The shared
spare-magazine latch transaction drops the installed magazine, retains the spare
and leaves the bolt, chamber and feed rail unchanged. A conservative oriented
box encloses the complete native magazine body, excluding `j_bullet`. The shared withdrawal
and 300 ms post-impact insertion rules apply; ordinary pull removal is unchanged.

Releasing the bolt, changing hands, stowing, dropping or losing tracking cancels
the hand constraint without completing the bolt motion. Existing carry transfer
snapshots retain these mechanical fields. Game checkpoint/load boundaries still
follow the existing physical reload lifecycle; this does not add serialization
of intermediate physical states to native save files.

## Source and presentation

Receiver: `h2_viewmodel_cheytac_base`, 17 bones. Native scope:
`attach_h2_cheytac_scope_vm`, four bones, with the alternate flat ADS subtree
hidden through the shared scope policy. Shared validated optic/suppressor
assemblies remain available. Barrel optics/magnification are not newly implemented.

The native weapon family is `cheytac`; a retained earlier firing trace records
five loaded rounds decreasing to four. Native capacity, bolt-action descriptor,
exact receiver skeleton and loaded rigid surface contracts must still pass
runtime admission. No game process was launched for this adaptation.

`j_bolt` rotates about its X axis and translates rearward. Normal `rechamber`
animation supplies approximately 52 degrees and 23.028 cm of travel. The source
right hand at frame 11 supplies the bolt grasp; only hand posture is mirrored
through the existing authoring convention, never the handle's actual side.
The authored comfort profile corrects ring/palm name matching. Left-hand
operation and right-hand palm-up use the same M14-derived finger chain, with
natural curl and clearance around the inclined Cheytac handle. The left-down
fit flips the complete right-up grasp about the plane through the actual handle
axis; both left-hand style entries share it. The native right-down grasp remains
available. See
[interaction comfort](vr-interaction-comfort.md).
Native `reload` frame 18 supplies the magazine grasp immediately before removal.
The initial candidate incorrectly reused `reload_empty` frame numbers against
`reload` and selected a pushing pose at frame 52. Frame 18 is an explicit reviewed
grasp, rather than an automatic nearest-contact choice. Mesh proximity is about
3.4 mm at the magazine and 0.44 mm at the bolt; controller comfort still needs
headset verification.

The magazine is `tag_clip`, with direct child `j_bullet`. Exported geometry has
874 magazine and 286 cartridge triangles with no crossing part boundaries.
The same native subset factory supplies the detached magazine and live ejected
cartridge. A cartridge in transit uses the source feed-rail/chamber endpoints;
its interpolation follows bolt travel rather than native animation time.
Only successful mechanical extraction emits the native spent-case effect.
Both case and live-round origins use the native `tag_brass` at the right-side
port. Live-round velocity follows the marker's local +X, which already points
right/up; applying gun-local -Y in that frame caused rearward ejection. The
native spent-case effect remains unchanged.
Firing retains the existing independent bullet, muzzle flash, sound and recoil
path. The manual bolt never receives the automatic spring-return or shot-driven
reciprocating motion of other profiles.

Receiver SHA-256:
`7895595603031f94d318cfb8b789bc1f4c10a5e4543885efe1862e738fdaf035`.
Authored pose headers retain animation hashes. Export tools and source paths
are local authoring aids, not runtime/build dependencies.

## Desert receiver assembly

The desert variant uses `h2_viewmodel_cheytac_base_desert` (17 bones),
`attach_h2_cheytac_scope_vm_desert` (4 bones), and the shared
`attach_h2_silencer_03_vm` (2 bones). Its receiver and scope preserve the same
bind matrices, names, parent indexes, and mechanical sound mappings as the
standard M200 assembly. They use the existing five-round magazine, poses, and
manual-bolt policy.

The desert receiver and scope have explicit registry entries. Its reload recipe
keeps the desert receiver as the rigid magazine source so detached geometry and
materials match the selected assembly. Admission checks retain the exact
receiver, attachment topology, native capacity, and catalog membership; unknown
names or an incorrect silencer parent are rejected.

The assembly regression fixture covers all 91 TF141, receiver, silencer, and
scope bones, including the native duplicate-parent links `85 -> 82` and
`87 -> 77`. Checks cover rig resolution, assembly selection, hand poses, reload
parts, muzzle binding, and rejection of unsupported topology. Runtime asset
admission and headset presentation remain separate acceptance steps.

## Diagnostics and acceptance

`vr_boltDebug 1` enables the existing stereo diagnostic renderer for this feed:
cyan path, orange ejection threshold, yellow rear threshold, green held point,
white eligible raw contact, red ineligible hand. Text shows the permitted stage
and live/spent/feeding/empty state. `vr_reload_interaction_status` includes lift,
travel, cocking, feed arming, ready state and the last interaction rejection.
`vr_weapon_fx_status` distinguishes shots from manual extraction requests.

Headset acceptance should cover right-side reach, grabbing after partial lift
or pull, grip handover, all five shots with manual cycling, empty and tactical
magazine changes, a reversed feed, drop/repickup and firing another weapon while
the M200 is open. Inspect cartridge alignment, normal scene depth, scope meshes
and both eyes. Diagnostics are disabled by default.

Automated checks exercise either-hand acquisition, retained grasp styles, partial lift/pull retention,
tracking loss, rejected native writes, case/live ejection, in-transit magazine
removal and 10,000 deterministic adversarial operation orders. Source assembly
tests add 36 M200 combinations to the precision-rifle suite. These checks do
not replace loaded native asset or headset verification.
