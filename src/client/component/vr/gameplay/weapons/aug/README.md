# AUG

H2 native `aug` family, 30-round closed-bolt magazine, physical pull removal,
manual handle catch and no automatic last-round lock. The arctic Steyr receiver
requires its foregrip with either rail or original scope. The bullpup magazine
well stays behind the primary hand. Native handle clips translate only; the
upward catch rotation is authored around the guide centre rather than the
receiver-centred animation bone. Physical removal uses the native clip-out sound.

See [shared behavior and source evidence](../../../../../../../docs/vr-manual-handle-catch.md).
