# MP5 / MP5K

H2 native `mp5` family, 30-round closed-bolt magazine, physical pull removal,
manual handle catch and no automatic last-round lock. Base/arctic receivers use
native MP5K hands. Body and round occupy separate materials; the skinned strap
stays outside the independent magazine. Its native front three-link chain uses
bounded, damped gravity/inertia motion beneath a fixed base ring; the rear strap
retains its native pose.

A held spare magazine can also strike the release paddle forward to drop the
seated magazine, using the shared AK latch policy. A conservative oriented
collider encloses the complete MP5K magazine body; the target is the lower
`j_clip_release` paddle behind the well. Both skins share these mesh contacts.
The spare stays held, ammunition is conserved, and insertion resumes after the
shared 300 ms clearance interval. Direct pulling and the manual handle catch
remain available. Headset reach/feel for the added strike route remains pending.
