# Campaign module

`scripted_sequences.*` observes native sequence context and publishes copied
policy. `sequences/` contains map classifiers and narrowly scoped script adapters.
Classifiers consume observations; their native adapters own VM access and live
entity/timeline witnesses.

`cliffhanger/` owns physical climbing, pickaxes and the mission detonator.
`cliffhanger/level_rules.hpp` combines checkpoint and collision-material rules
without importing the equipment runtime. `ending/` owns the finale interaction
and its physical presentation. Keep map exceptions with their map owner.

Native life, linking, inventory, script progression and camera/body authority
remain with H2. Phase observations must not acquire that authority merely because
a presentation snapshot is still fresh.
